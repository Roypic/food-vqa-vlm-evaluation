# Frozen prompting extension, 23 November 2026

The primary assignment uses baseline, task-structured CoT, and task-structured CoT + RAG on two frozen Qwen checkpoints. This extension uses the same image/text examples, correct-label input policy, JSON schema, greedy decoding, max-new-tokens 1024 and checkpoint revisions. No test-set examples are used as demonstrations and no targets are supplied to the model. These exploratory prompts were selected after examining prior results, so results are not a preregistered confirmation.

1. **Generic zero-shot CoT**: start from each baseline prompt; replace the baseline-only final directive with `Think step by step. Put a brief reasoning summary in reasoning_summary.` For nutrition, retain `fdc_ids_used=[]` and do not use retrieval. For recognition, retain the same schema and vocabulary. This differs in both instruction and permission to output a reasoning summary, so it is a prompt-condition comparison.
2. **Least-to-most nutrition**: one first call lists the foods and estimated/read weights in JSON, without requesting nutrition and without any ground-truth weights. A second call sees the original image or text, original baseline prompt, and unmodified first output, and estimates totals. The image stage receives the correct labels from the original input. The text stage receives the original question. It does not retrieve nutrients. Record both calls, invalid first-stage outputs, and final output. The harness has two calls and a changed prompt; the final output is scored regardless of first-stage validity.

Run zero-shot on all 20 images in open recognition, closed recognition and oracle-label nutrition, plus all 50 text questions, for each primary model (220 outputs). Run least-to-most on all 20 image and 50 text nutrition examples for each model (140 final outputs). Compare with existing baseline and structured CoT using matched valid examples; report validity/coverage, paired bootstrap intervals, item precision/recall/F1 and exact set, and nutrition MAE/MAPE. Do not interpret this as an independent benchmark or a statistically significant result merely because one average is lower. Preserve raw outputs and exclude invalid values only with counts.

Reference checkpoints: Qwen2.5-VL-7B `cc594898137f460bfe9f0759e9844b3ce807cfb5`; Qwen3-VL-4B `ebb281ec70b05090aa6165b016eac8ec08e71b17`. Original manifest and original predictions are read-only.
